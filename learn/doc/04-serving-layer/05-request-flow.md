# 请求处理完整流程

> 本章将前四章的知识串联起来，展示一条请求从 HTTP 到推理引擎的完整路径。

## 完整数据流

```
┌─────────────────────────────────────────────────────────┐
│                   客户端 (curl / SDK)                     │
│  POST /v1/chat/completions {"messages": [...], ...}      │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│               FastAPI 路由层                              │
│  api_server.py → chat_completion/ 路由处理                │
│    ├── 请求校验（parser 验证 JSON body）                    │
│    ├── Chat template 渲染（chat_utils.py）                 │
│    └── 构建 Engine API 调用参数                             │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│               Engine API 接口                             │
│  add_request(request_id, prompt, sampling_params, ...)   │
│  → 创建 Request 对象                                      │
│  → 调度器排队等待                                          │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼ (进入阶段二的推理管线)
┌─────────────────────────────────────────────────────────┐
│               推理引擎                                     │
│  Scheduler → Worker → Model Runner                       │
│  → Attention → Sampler → Output                          │
│  (详见阶段二文档)                                          │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│              响应格式化                                    │
│  StreamingResponse / JSONResponse                        │
│  SSE 格式逐 token / 完整 JSON                             │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────┐
│                   客户端收到响应                            │
└─────────────────────────────────────────────────────────┘
```

## 流式 vs 非流式

| 模式 | 实现 | 使用场景 |
|------|------|---------|
| **流式 (SSE)** | `StreamingResponse` + `EventSourceResponse` | 实时显示、低首 token 延迟 |
| **非流式** | 聚合完整输出后返回 JSON | 需要完整结果的批量处理 |

引擎通过 `scheduler_output.finished_requests` 判断请求是否完成，完成后将输出发送到响应通道。
