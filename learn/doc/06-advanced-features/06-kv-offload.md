# KV Cache 卸载

## 文件位置

`vllm/v1/kv_offload/` 目录

## 动机

当上下文极长（>128K tokens）时，KV Cache 占用的显存可能超过 GPU 容量。将部分 Cache 卸载到 CPU 内存可以在显存受限时支持更长的上下文。

## 卸载策略

```
GPU 显存                     CPU 内存
┌──────────────────┐        ┌──────────────────┐
│ 活跃的 KV Cache   │   ←→  │ 卸载的 KV Cache  │
│ (当前层)          │  PCIe │ (历史层)         │
└──────────────────┘        └──────────────────┘
```

- **卸载时机**：AI 预测当前层的 Cache 在后续步中使用概率低时
- **传输方式**：通过 PCIe 异步传输，与计算重叠
- **再加载**：当被卸载的 Cache 再次需要时，异步加载回 GPU

## 简化卸载

`v1/simple_kv_offload/` 提供一个简化版本，适合不需要复杂预测策略的场景。
